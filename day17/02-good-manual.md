# 설치 방법 (사용자 기준 — 좋은 예)

## 1. 프로그램을 내려받습니다

공식 사이트에서 **Windows용 설치 파일**을 내려받습니다.

## 2. 내려받은 파일을 실행합니다

내려받기 폴더에서 파일을 두 번 누르면 설치 창이 열립니다.
설치 옵션은 **모두 기본값**으로 두고 **다음**을 누릅니다.

## 3. 설치가 끝나면 프로그램이 열립니다

첫 화면에 **환영 탭**이 보이면 설치가 끝난 것입니다.

## 잘 안 될 때

| 증상 | 해결 |
|:---|:---|
| 설치 창이 안 열린다 | 파일을 **오른쪽 클릭 → 관리자 권한으로 실행** |
| 설치가 중간에 멈춘다 | 백신 프로그램을 잠시 끄고 다시 실행 |
