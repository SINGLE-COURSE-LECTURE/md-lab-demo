# 마크다운 문서 작성 사용자 매뉴얼

## 1. 개요

설치가 끝난 뒤 **문서를 쓰고 저장소에 올리기까지** 하는 방법입니다.

## 2. 문서 만들기

1. 왼쪽 탐색기에서 **새 파일** 아이콘을 누릅니다
2. 이름을 `README.md` 로 적습니다 — **`.md` 로 끝나야** 마크다운으로 인식됩니다
3. 아래를 그대로 적어 봅니다

```text
# 내 첫 문서

이것은 **굵은 글자**입니다.
```

## 3. 미리보기로 확인하기

**Ctrl+K** 를 누르고 손을 뗀 뒤 **V** 를 누릅니다. 오른쪽에 미리보기가 열립니다.

왼쪽을 고치면 오른쪽이 **바로** 바뀝니다.

## 4. 저장소에 올리기

터미널을 열고(**보기 → 터미널**) 아래를 차례로 칩니다.

```text
git add README.md
git commit -m "docs: 첫 문서 추가"
git push
```

## 5. 잘 안 될 때

| 증상 | 원인 | 해결 |
|:---|:---|:---|
| 미리보기가 안 열린다 | 확장이 없다 | `Markdown All in One` 을 설치한다 |
| `nothing added to commit` | `git add` 를 빠뜨렸다 | `git status` 로 확인한다 |
| 굵은 글자가 안 된다 | 별표가 하나다 | 별표를 **두 개**씩 감싼다 |
