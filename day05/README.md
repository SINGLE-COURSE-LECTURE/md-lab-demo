## 비교 방법

같은 파일을 **두 곳**에서 엽니다.

1. **VS Code 미리보기** — `Ctrl+K` 다음 `V` (2층 GFM 까지 지원)
2. **CommonMark 시험장** — <https://spec.commonmark.org/dingus/> (1층 표준만 지원)

`01-gfm.md` 를 양쪽에 넣으면 **제목·문단은 같고 확장 네 가지만 달라집니다.**
