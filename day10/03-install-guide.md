# VS Code 설치 안내

작성자: 홍길동 · 갱신: 2026-09-17

## 1. 내려받기

공식 사이트에서 설치 파일을 내려받습니다.

![공식 사이트 첫 화면에 Download for Windows 버튼이 파란색으로 크게 표시된 모습](assets/10-step1-download.png)

**그림 1.** 내려받기 — 가운데 파란 버튼을 누릅니다.

## 2. 설치 시작

내려받은 파일을 실행하면 사용권 계약 화면이 나옵니다.

![설치 마법사 첫 화면에 사용권 계약 동의 선택이 있는 모습](assets/10-step2-license.png)

**그림 2.** 사용권 동의 — 동의를 선택해야 다음으로 넘어갑니다.

## 3. 옵션 선택

바탕화면 아이콘과 PATH 추가를 선택합니다.

![설치 옵션 화면에 여러 체크박스가 나열되고 PATH 추가 항목이 선택된 모습](assets/10-step3-option.png)

**그림 3.** 옵션 — **PATH 추가**는 반드시 켭니다.

## 4. 설치 진행

진행 막대가 끝까지 차기를 기다립니다.

![설치 진행 화면에 가로 진행 막대가 절반쯤 찬 모습](assets/10-step4-progress.png)

**그림 4.** 진행 — 몇 분 걸립니다.

## 5. 버전 확인

터미널에서 버전을 확인해 설치를 검증합니다.

![터미널에 버전 명령을 입력해 버전 번호가 출력된 모습](assets/10-step5-version.png)

**그림 5.** 버전 확인 — 번호가 나오면 성공입니다.

## 확인 사항

- 모든 이미지에 대체 텍스트를 달았는가
- 캡처에 계정명·이메일이 찍히지 않았는가
- 상대 경로로 넣었는가
